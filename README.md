# PUBG Cards: сбор карточек коллекции

Android-приложение (Kotlin, без внешних библиотек, Android 11+).
Само листает карты в игре, делает скриншоты, вырезает карточки и собирает zip в `Загрузки/PUBG_cards`.

## Как получить APK

**Вариант 1: GitHub (проще всего, ничего ставить не нужно)**
1. Создай репозиторий на github.com и загрузи в него всё содержимое этой папки (включая скрытую `.github`).
2. Открой вкладку **Actions**, дождись зелёной галочки у «Build APK».
3. Открой запуск, внизу в **Artifacts** скачай `PubgCards-APK`, распакуй, установи `app-debug.apk` на телефон.

**Вариант 2: Android Studio**
Open → выбери эту папку → дождись синхронизации → Build → Build APK(s).

## Первый запуск
1. Установи APK, открой «PUBG Cards».
2. Нажми «Открыть настройки специальных возможностей», найди **PUBG Cards Collector**, включи.
   Если Android пишет про «ограниченные настройки»: «Сведения о приложении» → ⋮ → «Разрешить ограниченные настройки», потом снова включи службу.
3. Нажми «Настроить точки»: откроется игра, поверх неё появятся розовые блоки. Перетащи **центр креста** на нужное место и жми «Далее». Кнопка «Подсказка» показывает фото-пример.
4. Нажми «Собрать…», открой в игре меню коллекции и нажми «▶ Старт» в розовой панели.

Игра должна быть в горизонтальной ориентации.
